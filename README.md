## What it does

Vendor Risk Screener assesses every supplier across security posture, financial stability, compliance certifications, and adverse media — with continuous monitoring after onboarding.

## Key features

- **Multi-signal scoring** — security ratings, breaches, finances, sanctions lists.
- **Questionnaire AI** — vendor security questionnaires auto-analyzed.
- **Continuous monitoring** — re-scored on new breaches or news.
- **Tiering rules** — critical vendors get deeper review automatically.
- **Fourth-party mapping** — your vendors' vendors surfaced.

## Who it's for

Procurement and security teams onboarding vendors faster than manual review allows.
